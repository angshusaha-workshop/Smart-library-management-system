# Smart Library Management System

A Python-based Smart Library Management System designed to manage books, members, borrowing activities, transactions, and library insights through a simple command-line interface.

## Features

- Admin Login System
- Add, View, Search, Update & Delete Books
- Register, View, Search, Update & Delete Members
- Issue & Return Books
- Automatic Fine Calculation for Late Returns
- Transaction History
- Member Borrowing History
- Smart Book Recommendation System
- Library Dashboard
- Overdue Book Tracking
- Library Popularity Report
- Activity Log
- JSON-based Data Storage

##  Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
- Exception Handling
- Date & Time
- Command Line Interface (CLI)
